# 🌦️ Atmos – Weather Dashboard

A modern and responsive weather dashboard built using **HTML, CSS, and JavaScript**. This project fetches real-time weather information from the OpenWeatherMap API and displays live weather conditions for any city searched by the user.

## 🚀 Live Features

- 🔍 Search weather by city name
- 🌡️ Real-time temperature
- 💧 Humidity
- 💨 Wind Speed
- 🌍 Pressure
- 🌤️ Feels Like Temperature
- 🌥️ Weather Description
- 🖼️ Dynamic Weather Icons
- 📅 Current Day & Date
- 📱 Responsive Design
- ⚡ Fast API Fetch using Async/Await
- ❌ Error handling for invalid cities

---

## ⚙️ Getting Started

1. Clone the repository

```bash
git clone https://github.com/your-username/weather-dashboard.git
```

2. Open the project folder.

3. Add your OpenWeatherMap API Key inside **api.js**

```javascript
const apiKey = "YOUR_API_KEY";
```

4. Open **index.html** in your browser.
